# Web-ready images

**Don't put your original files here — they go in `/assets/source-images/`.**

Everything in this folder is public: it is served directly to anyone who visits
the site. These are the processed, optimised versions, produced from the
originals.

The site refers to images in here by address, starting from `/images/`. So
`public/images/hero-athlete.png` is reached as `/images/hero-athlete.png`.

Next.js handles resizing and modern formats automatically at request time, so
there is no need for a separate file per screen size — one good-quality image
per subject is enough.

Empty for now; the first images land here once the originals arrive.
